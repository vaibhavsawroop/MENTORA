# MentoraX

A React + TypeScript frontend app for the MentoraX mentoring platform — targeted at IAT & NEST aspirants preparing for IISER admissions.

## Stack

- **React 19** + **TypeScript** via **Vite**
- **Three.js** / **@react-three/fiber** — 3D hero scene
- **Framer Motion** — page transitions and animations
- **React Router v7** — client-side routing
- **OGL** — canvas-based visual effects

## How to run

The app runs on port 5000 via the "Start application" workflow:

```
npm run dev
```

No backend or environment secrets are required — this is a pure frontend project.

## Build

```
npm run build
```
